HOW TO ADD MORE GENERATORS LATER:

Option A: No coding - Use UI
  AI Menu -> Manage AI Providers -> Add Custom API Provider
  Enter: Name + URL with {prompt}, {width}, {height} placeholders
  Example URL: https://myapi.com/generate?prompt={prompt}&w={width}&h={height}

Option B: Python plugin (more control)
  1. Open ai_generators folder: AI Menu -> Open ai_generators Folder
  2. Create new file: my_generator.py
  3. Copy template from _example_plugin.py
  4. Implement generate function that returns PIL Image
  5. Restart app - your provider appears in list!
